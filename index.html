☁️ Cloudflare Stream Proxy (Mainokseton Pilvi)

🛡️ 100% Mainokseton YouTube-toisto GitHub Pagesissa:
Tämä yhdistää soittimen omaan ilmaiseen Cloudflare Workeriisi, joka poistaa mainokset ja toistaa videot suoraan selaimen omalla HTML5-soittimella.

Cloudflare Worker URL-osoite:

Nopea käyttöönotto (2 min, 100 % ilmainen):
  1. Kirjaudu osoitteeseen dash.cloudflare.com (ilmainen tili).
  2. Valitse vasemmalta Compute (Workers & Pages) > Create application > Create Worker.
  3. Paina Deploy, ja sen jälkeen Edit code.
  4. Liitä cloudflare-worker.js -tiedoston sisältö editoriin ja paina Deploy.
  5. Kopioi workerin .workers.dev -osoite ja liitä se yllä olevaan kenttään!
